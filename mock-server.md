# Mock-сервер и коллекция Postman

В проекте нет backend. Mock-сервер заменяет его на этапе проверки контракта: [Prism](https://github.com/stoplightio/prism) читает [`event-management-api.yaml`](event-management-api.yaml) и отвечает примерами из спецификации. Коллекция Postman отправляет запросы к mock-серверу и проверяет ответы.

## Запуск mock-сервера

На компьютере должен быть установлен Node.js.

1. Скачайте репозиторий или распакуйте архив проекта.
2. Откройте терминал в папке, где находится `event-management-api.yaml`.
3. Выполните команду:

```bash
npx @stoplight/prism-cli mock event-management-api.yaml
```

По умолчанию Prism запускается на `http://127.0.0.1:4010`. В этой конфигурации пути доступны без префикса `/v1`, указанного в условном базовом URL сервера. Поэтому маршрут начинается сразу после порта:

```bash
curl "http://127.0.0.1:4010/events?date=2026-11-14"
```

Если Prism возвращает `NO_PATH_MATCHED_ERROR`, сравните URL с путями в спецификации. Не добавляйте `/v1`.

## Получение ответов с ошибками

По умолчанию Prism возвращает пример успешного ответа. Чтобы запросить документированный пример ошибки, передайте заголовок `Prefer`:

```bash
curl -X PUT "http://127.0.0.1:4010/events/evt-1042/cabin" \
  -H "Content-Type: application/json" \
  -H "Prefer: code=409, example=conflict"
```

Доступность конкретного примера зависит от содержимого OpenAPI и поведения версии Prism. Если ошибка не возвращается ожидаемым образом, сверяйтесь со спецификацией и логом Prism.

## Импорт коллекции в Postman

1. Откройте Postman и нажмите **Import**.
2. Выберите файл `event-management-api.postman_collection.json` из этой папки.
3. Импортируйте коллекцию.
4. Проверьте, что переменная `baseUrl` указывает на `http://127.0.0.1:4010` либо передайте её при запуске Newman.
5. Убедитесь, что терминал с Prism остаётся открытым.
6. Запустите коллекцию через **Run**.

## Запуск коллекции через Newman

Если Newman не установлен глобально, можно выполнить:

```bash
npx newman run event-management-api.postman_collection.json --env-var "baseUrl=http://127.0.0.1:4010"
```

Коллекция содержит 18 запросов и рассчитана на 36 проверок. Проверки включают HTTP-статус, ключевые поля успешного ответа или документированный код ошибки.

## Ограничения проверки

Успешный прогон на mock-сервере не доказывает, что реальная система сохраняет данные, проверяет бизнес-правила или защищает от параллельных бронирований. Prism использует контракт и примеры, поэтому такие результаты следует трактовать как **проверку согласованности API-контракта**, а не как полноценное интеграционное или бизнес-тестирование.

Файл `newman-results.png` отражает предыдущий базовый прогон. После запуска обновлённой коллекции обновите скриншот, чтобы он соответствовал актуальным проверкам.
